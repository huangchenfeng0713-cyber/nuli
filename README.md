# 逗包

朋友之间的恶搞网页：一个智力固定、努力程度可以从「摆烂」一路拉到「飞升」的 AI 聊天页。跟任何真实产品都没有关系。

- 打开：https://huangchenfeng0713-cyber.github.io/nuli/
- 回答由页面里的离线小脑袋生成：算数、单位换算、日期倒计时、常识、古诗、笑话、帮你做选择。
- 「我的 › 逗包形象」上传照片后，会自动识别五官，生成 8 种努力形态。照片只存在本机浏览器里。
- 想让所有人打开链接就看到同一张脸：在仓库根目录放一张 `preset.jpg`（可选再放 `preset.json` 写对齐参数）。注意仓库是公开的。

第三方：人脸识别用了 [face-api](https://github.com/vladmandic/face-api)（MIT，见 `fa/LICENSE`）和 [picojs](https://github.com/nenadmarkus/picojs)（MIT）。
